# spacemission_analysis
Space Mission Data Analysis using Python, Pandas, Excel, and Power BI to analyze mission trends, launch outcomes, organizations, and space mission performance.
Space Mission Data Analysis

This project analyzes **space mission data** to identify trends and patterns in space launches, mission outcomes, organizations, and mission performance.

Tools Used

* Python
* Pandas
* Matplotlib
* Excel
* Power BI

Analysis Areas

* Total number of space missions
* Mission success and failure rates
* Launch trends over time
* Mission status analysis
* Organization/company performance
* Mission types and categories
* Year-wise mission trends

Project Objective

The main objective of this project is to transform raw space mission data into meaningful insights through **data cleaning, exploratory data analysis, visualization, and interactive dashboards**.

 Skills Demonstrated

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Python & Pandas
* Data Visualization
* Excel Analysis
* Power BI Dashboard Development
* Business/Data Insights
